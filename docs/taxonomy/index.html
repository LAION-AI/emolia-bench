VoiceNet-Ext Dimension Taxonomy

A comprehensive rubric of 57 voice performance attributes for fine-grained speech understanding

57 dimensions · ~7 ordinal levels each · 10 attribute groups
Annotation protocol: For each (dimension, level) bucket, candidate audio clips were pre-screened by Gemini 3 Flash. An equal number of positives (confirmed to match the target level) and negatives (confirmed to match a non-adjacent level of the same dimension) were presented to Bachelor-of-Psychology annotators, who performed a binary confirm/reject judgement.
